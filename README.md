# jliittrell.com

Personal portfolio website for Jason Littrell - Software Developer & Technology Professional

## Features

- ✅ **SEO Optimized**: Comprehensive meta tags, Open Graph, Twitter Cards, and structured data
- ✅ **Responsive Design**: Mobile-first approach with smooth transitions across all devices
- ✅ **Modern UI/UX**: Clean, professional design with smooth animations and interactions
- ✅ **Performance**: Optimized loading with lazy loading and efficient CSS/JS
- ✅ **Accessibility**: WCAG compliant with proper semantic HTML and ARIA labels
- ✅ **Cross-browser Compatible**: Works seamlessly across all modern browsers

## Technologies Used

- **HTML5**: Semantic markup with structured data
- **CSS3**: Modern styling with CSS Grid, Flexbox, and custom properties
- **Vanilla JavaScript**: No dependencies, pure JS for optimal performance
- **Google Fonts**: Inter font family for clean typography

## SEO Features

1. **Meta Tags**: Comprehensive title, description, and keyword tags
2. **Open Graph**: Social media sharing optimization
3. **Structured Data**: JSON-LD schema for better search engine understanding
4. **Sitemap**: XML sitemap for search engine crawlers
5. **Robots.txt**: Proper crawler directives
6. **Semantic HTML**: Proper use of header, nav, section, article tags
7. **Mobile Optimization**: Responsive design with proper viewport settings
8. **Performance**: Fast loading times and optimized assets

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. For production: Deploy to any static hosting service (GitHub Pages, Netlify, Vercel, etc.)

## Customization

### Update Content
- Edit `index.html` to update personal information, projects, and skills
- Modify social media links and contact information

### Change Colors
- Update CSS custom properties in `styles.css` (`:root` section)
- Main colors: `--primary-color`, `--secondary-color`, `--accent-color`

### Add Projects
- Add new `<article>` elements in the projects section
- Include project images in an `assets/` folder

## Performance Tips

1. Add actual project images and use lazy loading (already implemented in JS)
2. Compress images before uploading (use WebP format when possible)
3. Enable Gzip/Brotli compression on your server
4. Use a CDN for static assets
5. Implement caching headers
