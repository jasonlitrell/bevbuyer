# SUPER SIMPLE GUIDE - How to Add Your Website to GoHighLevel

Follow these exact steps. Don't skip any!

---

## STEP 1: Get the Code Ready

### Option A: If you're reading this on your computer
1. Find the file called **`hospitality-consulting-ghl.html`** in this folder
2. Right-click on it
3. Click "Open With" → "Notepad" (Windows) or "TextEdit" (Mac)
4. When it opens, press **Ctrl+A** (Windows) or **Cmd+A** (Mac) - this selects everything
5. Press **Ctrl+C** (Windows) or **Cmd+C** (Mac) - this copies it
6. **DONE!** The code is copied. Move to Step 2.

### Option B: If you're not sure how to find the file
1. I'll create a simpler copy below that you can use
2. Skip to Step 2

---

## STEP 2: Go to GoHighLevel

1. Open your web browser
2. Go to your GoHighLevel login page
3. Log in to your account
4. You should see your dashboard

---

## STEP 3: Create a New Website in GoHighLevel

1. On the left side menu, look for **"Sites"** or **"Websites"**
2. Click on it
3. Click the **"+ New Website"** button (usually blue, at the top)
4. A popup will appear asking you to choose a template

---

## STEP 4: Choose How to Add the Code

### Method 1: Custom Code (If you see this option)
1. Look for **"Custom Code"**, **"Blank Template"**, or **"Custom HTML"**
2. Click that option
3. Click "Continue" or "Create"
4. You should now see a page builder

### Method 2: Funnel Builder (Alternative)
1. If you don't see "Custom Code", click **"Blank"** or **"Start from Scratch"**
2. Click "Continue"
3. You'll see a drag-and-drop editor

---

## STEP 5: Add the Code

### If you're in the Page Builder:
1. Look for an element called **"Custom Code"** or **"HTML"** in the left sidebar
2. Drag it onto the page
3. Double-click on it to edit
4. A text box will appear
5. **Delete everything** in that text box
6. Press **Ctrl+V** (Windows) or **Cmd+V** (Mac) to paste your code
7. Click "Save" or "Apply"

### If you're in a code editor:
1. You should see a big text area
2. **Delete everything** in it
3. Press **Ctrl+V** (Windows) or **Cmd+V** (Mac) to paste your code
4. Click "Save"

---

## STEP 6: Preview Your Website

1. Look for a **"Preview"** button (usually at the top)
2. Click it
3. Your website should appear!
4. If it looks good, click **"Publish"** or **"Save"**

Your GoHighLevel plan might not support custom code. Try this instead:
